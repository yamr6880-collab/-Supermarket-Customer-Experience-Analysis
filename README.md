## Project Overview
This Power BI dashboard analyzes customer experience and sales performance across supermarket branches.  
The dashboard provides insights into customer satisfaction, product performance, payment preferences, and branch ratings to support data-driven business decisions.

---

## Objectives
- Analyze customer satisfaction across branches
- Identify top-performing product lines
- Compare ratings by customer type and payment method
- Explore sales performance alongside customer experience metrics

---

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

---

## Key KPIs
- Average Customer Rating
- Total Sales
- Customer Count
- Top Rated Branch
- Lowest Rated Branch

---

## Dashboard Features
- Interactive slicers for:
  - City
  - Branch
  - Payment Method

- Customer satisfaction analysis
- Product line performance comparison
- Payment method rating analysis
- Customer type comparison
- Branch performance tracking

---

## Key Insights
- Branch C achieved the highest customer satisfaction score.
- Food & Beverages received the highest customer ratings.
- Customer ratings remained relatively consistent across payment methods.
- Normal customers showed slightly higher average ratings than members.
